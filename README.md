# 퀴즈 프로그램

Python으로 만든 터미널 기반 퀴즈 프로그램입니다.
퀴즈를 등록·삭제하고, 목록을 확인하고, 퀴즈를 풀어 점수를 계산할 수 있습니다.
퀴즈는 JSON 파일에 저장되어 프로그램을 껐다 켜도 유지됩니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 퀴즈 풀기 | 등록된 퀴즈를 순서대로 출제하고 점수(맞은 개수, 백분율)를 보여줍니다 |
| 퀴즈 목록 | 등록된 퀴즈를 번호와 함께 출력합니다 |
| 퀴즈 등록 | 문제와 정답을 입력받아 추가하고 파일에 저장합니다 |
| 퀴즈 삭제 | 번호를 선택해 퀴즈를 삭제하고 파일에 저장합니다 |
| 자동 저장/불러오기 | `quizzes.json` 파일로 퀴즈를 보관합니다 |
| 정답 비교 | 앞뒤 공백과 대소문자를 무시합니다 (`" h2o "` = `"H2O"`) |
| 오류 처리 | 숫자가 아닌 입력, 없는 번호, 손상된 저장 파일을 안전하게 처리합니다 |

## 실행 방법

### 요구 사항

- Python 3.6 이상 (f-string 사용)
- 별도로 설치할 라이브러리 없음 (표준 라이브러리 `json`만 사용)

### 실행

```bash
python quiz.py
```

> 파일 이름은 `quiz.py`가 아니어도 됩니다. 저장한 파일 이름으로 실행하세요.

### 사용 예시

```
1.퀴즈 풀기 2.목록 3.등록 4.삭제 5.종료
선택: 3
문제: 대한민국의 수도는?
정답: 서울
등록되었습니다.

1.퀴즈 풀기 2.목록 3.등록 4.삭제 5.종료
선택: 1
대한민국의 수도는? 서울
정답!

결과: 1/1 (100점)
```

## 파일 구조

```
.
├── quiz.py          # 프로그램 본체
├── quizzes.json     # 퀴즈 데이터 (처음 퀴즈를 등록하면 자동 생성)
└── README.md
```

### 데이터 형식 (`quizzes.json`)

```json
[
  {
    "question": "대한민국의 수도는?",
    "answer": "서울"
  }
]
```

직접 파일을 수정해도 되지만, JSON 형식이 깨지면 프로그램이 빈 목록으로 시작합니다.

## 기능 목록

| 함수 | 역할 |
|------|------|
| `load_quizzes()` | 파일에서 퀴즈를 불러옴 (파일이 없거나 손상되면 빈 리스트) |
| `save_quizzes()` | 현재 퀴즈 목록을 파일에 저장 |
| `list_quizzes()` | 퀴즈 목록 출력 |
| `add_quiz()` | 퀴즈 등록 |
| `delete_quiz()` | 퀴즈 삭제 |
| `is_correct()` | 정답 비교 (공백·대소문자 무시) |
| `play_quiz()` | 퀴즈 출제와 점수 계산 |
| `main()` | 메뉴 반복 실행 |

이 프로젝트는 20개 미션으로 점진적으로 개발합니다.

- [x] **1단계 (미션 1~3)**: 입력·출력, 조건문
